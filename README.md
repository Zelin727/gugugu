# 咕咕嘎嘎 · 雪原大冒险

支持手机横屏触控和电脑键盘的单人 H5 闯关游戏。七章关卡，包含奶球攻击、防御、跳跃、双次冲撞、随机强化和最终战大招。

游戏地址：https://zelin727.github.io/gugugu/

## 操作

手机：左侧拖动移动，按住奶球持续瞄准攻击。点按防御切换状态，点击技能按钮使用跳跃、冲撞、咕咕嘎嘎和补给。

电脑：WASD / 方向键移动，F 发射奶球，空格防御，J 跳跃，Shift 冲撞，E 咕咕嘎嘎，Q 罐头补给，Esc 暂停。

冲撞在第一章通关后解锁；咕咕嘎嘎需要满笑意。章节进度保存在当前浏览器，换设备不会自动同步。

## 发布与更新

这是无需编译的静态网站。GitHub Pages 使用 `main` 分支的根目录发布，`.nojekyll` 禁用不需要的 Jekyll 处理。修改后提交到 `main`，Pages 会更新网站。

HTML、JavaScript、CSS 和图片均存放在此仓库；游戏运行不需要 ChatGPT 账号或 OpenAI API。

在本机测试可运行：

```sh
python3 -m http.server 8000
```

然后访问 http://localhost:8000/ 。
